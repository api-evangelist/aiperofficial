# Aiper

> Aiper is a consumer robotics company selling cordless robotic pool cleaners, solar pool skimmers
> and smart yard-care hardware (Scuba, Surfer/EcoSurfer, Pilot, IrriSense). Devices pair to the
> Aiper mobile app. Aiper publishes NO public API, developer portal, SDK, or machine-readable
> contract. This file was generated by API Evangelist from the catalog record, not published by
> Aiper.

## API surface

- No public developer API. There is no developer portal, API reference, OpenAPI/AsyncAPI/GraphQL
  contract, SDK, webhook catalog, MCP server, or agent card anywhere on an Aiper host.
- A real first-party cloud control plane exists but is private to the mobile app: regional hosts
  https://apiamerica.aiper.com, https://apieurope.aiper.com and https://apiasia.aiper.com, fronted
  by FortiWeb Cloud, plus an AWS IoT MQTT layer. Every anonymous request to any path on those
  hosts - including /.well-known/* - returns HTTP 200 with the JSON envelope
  {"code":"401","message":"Your login has expired..."}. There is no anonymous surface to read.
- The only machine clients that speak it are unofficial community reverse-engineering projects:
  https://github.com/kmich/ha-aiper (Home Assistant), https://github.com/dje2912/ha-aiper,
  https://www.npmjs.com/package/homebridge-aiper (HomeKit). None is endorsed by Aiper.
